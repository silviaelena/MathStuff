## What's in here

I've got three main things going on:

### Differential Equations

[`differential-equations/`](differential-equations/)

Been working through differential equations with Python. Mostly trying to understand why they show up everywhere and how to solve/visualize them. Some conceptual notes about what DEs actually mean, plus code for solving ODEs and plotting direction fields.

---

### Imperial College ML Math Course

[`imperial-college-mathematics-for-ml-specialization/`](imperial-college-mathematics-for-ml-specialization/)

Working through the Imperial College math for ML specialization. So far I've done:

- **Calculus module** - The sandpit exercise was actually pretty cool. It's an interactive thing where you find a phone in sand using gradient descent. Made me finally get why gradient descent works the way it does.

- **PCA module** - Started with mean, covariance, and affine transformations. Learned the hard way that vectorization matters a lot - my naive loops were embarrassingly slow.

The summaries are AI-generated (see disclaimer above) - they help me process dense papers faster, but I'm not using them for anything formal.
